# MiniProjectAR

Aplikasi Augmented Reality (AR) yang dirancang untuk melakukan *tracking* pada *image target* secara *real-time* dan menampilkan objek 3D di atasnya.

---

## 📌 Fitur Utama

- **Image Target Detection**: Mendeteksi gambar target yang sudah didaftarkan dengan akurasi tinggi.
- **3D Object Rendering**: Memunculkan dan memposisikan objek 3D secara presisi di atas *image target*.
- **Real-Time Tracking**: Melakukan pelacakan perpindahan dan pergerakan target secara responsif.

---

## 🚀 Alur Kerja / Cara Kerja

1. **Arahkan Kamera**: Pengguna mengarahkan kamera perangkat ke *image target* yang sesuai.
2. **Deteksi Target**: Sistem memproses input visual dari kamera untuk mengenali pola pada gambar target.
3. **Visualisasi Objek 3D**: Objek 3D dirender dan ditempatkan tepat di atas gambar target secara otomatis.
